# ReelProof personal iPhone test

Personal-device research build for iPhone and iPad. Source and the macOS build workflow are prepared for the `codex/reelproof-personal-ios` branch under `reelproof-personal/`.

The device IPA must be development-signed with your own Apple account before installation from Windows. Gemini API keys and Apple signing credentials are not stored in this repository. A build artifact is only provided after a successful macOS build; real-device testing is still required.
